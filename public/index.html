how-it-works

Three steps. About ninety seconds.

Create temporary credentials

Use aws sts get-session-token, an SSO session, or a read-only IAM user. 3am_blueprint only ever calls Describe* / List* / Get*.

Pick a scope & regions

A tag like Project=checkout, a VPC picked from a live dropdown, or the whole account. Sweep every region if you're not sure where things live.

Browse & export

The diagram renders in seconds. Explore it interactively, then download the SVG/PNG or copy a share link.

security

Built to be trusted with keys.

Same philosophy as the rest of the 3am_ stack: your data stays on your infrastructure, and trust is earned by design, not asked for.

Credentials never touch disk

Keys are used for your scan's API calls, held in memory, never persisted, never logged.

Read-only by design

Every AWS call is a read. There is no code path that mutates your account.

Temporary by default

Built for STS session tokens that expire on their own. Long-lived keys are discouraged in the UI.

Self-hostable

Run it on your laptop or in your VPC with one command — keys never leave your network. MIT licensed.

self-host
